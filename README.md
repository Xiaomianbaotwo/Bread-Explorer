# 🍞 面包浏览器 (Bread Explorer)
> “在信息的汪洋中，为你烤制一份最纯粹的导航面包。”
“面包浏览器”不仅仅是一个简单的个人网址导航站，而是一个集成了**沉浸式视觉体验、云端账号生态、虚拟经济系统**与**高性能视觉特效**的综合性 Web 个人数字空间。

### 🌟 项目愿景与开发理念
本项目诞生于对“极致轻量”与“高度定制化”的追求。我们抛弃了沉重的前端框架（如 Vue、React），完全采用**原生 HTML5 + CSS3 + 纯 JavaScript (ES6+)** 构建。这种极客式的开发方式，不仅保证了网页在任何设备上的“秒开”体验，更赋予了开发者对每一行代码、每一次动画帧的绝对控制权。

### 🛠️ 技术架构演进
项目最初采用纯前端架构，依靠浏览器的 `LocalStorage` 进行本地数据存储。

- **`v0.0.2`**：初始基础版本，完成项目骨架搭建，确立**全局单资源根目录**架构规范，全项目仅保留唯一根目录 `assets/`，统一管理字体、图片、音频等全部静态资源；完成主站基础页面、基础登录框架；搭建附属子站 `bread‑article‑appreciation`（文章赏析附属站）入口与登录态打通。
  1. 资源收口：移除附属站内部独立 `assets`、`images` 等资源文件夹，禁止子目录复制资源、软链接镜像；所有静态资源归置根目录 `assets` 的子分类目录。
  2. 路径约束：附属站页面、CSS 采用向上相对路径引用根资源，字体复用主站 `css/06‑fonts.css`，禁止拷贝字体文件。
  3. 代码隔离：附属站 JS 脚本保持完全独立，不与主站同名业务脚本合并，避免全局变量冲突。
  4. 验证标准：内置 HTTP 服务实测校验，确认全部资源请求200、控制台无报错，登录态、页面功能、烟花特效正常可用。

### 📂 项目结构
- `index.html`: 主页面
- `assets/`: **全项目唯一静态资源根目录**
  - `assets/fonts/`: 存放本地内置的中英文字体
  - `assets/images/`: 项目图片资源
  - `assets/audio/`: 项目音频资源
- `bread‑article‑appreciation/`: 文章赏析附属子站（仅存放子站专属HTML、css、js业务代码，无独立资源目录）
- `css/`: 样式表（变量、基础、布局、弹窗、特效、字体等；好友专属样式已随模块迁到 `modules/friend/css/`）
- `js/`: 主站核心脚本模块（核心引擎、配置、UI、登录、主题、邮件、积分、红包雨、开发者、烟花、更新检测）
- `modules/i18n/`: **国际化模块**（无 CSS，JS 直接放目录下）：`01‑i18n‑core.js` 内核 + 全局 `_loadT`，`02‑i18n‑ui.js` / `03‑i18n‑social.js` / `04‑i18n‑account.js` / `05‑i18n‑system.js` 按模块拆分且**每个文件内同时含中英双语词条**，`06‑i18n‑init.js` 交给 i18next 并绑定语言选择器
- `modules/friend/`: **独立社交模块**（`js/01‑friends‑core.js` 入口、`02‑friends‑list.js` 好友列表与搜索、`03‑friends‑chat.js` 聊天逻辑、`04‑friends‑chat‑render.js` 气泡渲染、`05‑friends‑gift.js` 送礼；`css/01‑friends.css` 好友样式）
- `modules/weather/`: **天气模块**（`js/01‑config.js` 配置、`02‑weather‑core.js` 主站天气逻辑；`css/01‑weather.css` 样式；`cities/` 各国城市数据 txt）

### ✨ 核心功能
1. **多主题与视觉特效**：内置多套精美主题，自带基于 Canvas 的高性能烟花引擎与动态红包雨互动。
2. **字体深度定制**：中英文字体双向隔离加载，支持系统内置读取与网页端自定义上传，全部字体资源统一托管于根目录 `assets/fonts/`。
3. **附属文章赏析子站**：独立子站点，共享主站登录会话状态，业务代码完全隔离，复用主站全部静态资源。
4. **极客开发者面板**：内置需要多重密钥与 UUID 强校验的三端代码执行器（前端 JS），配备本机免密通行证。

> ### ⚠️ **特别注意事项：**
> 当前为初始版本 `v0.0.1`，附属文章赏析站为内测附属站点。
> 如果在使用过程中遇到报错，请您通过主页左上角的【📮建议箱】直接向开发者反馈，我们非常非常欢迎您反馈问题，我们会火速修复！
